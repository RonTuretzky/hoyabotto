# Saved calibration for farm_xlerobot

Exported from the robot Mac on 2026-10-05 at the operator’s request. This is a snapshot of the saved LeRobot calibration, not a new calibration run. It contains all 16 motors: left arm, head, right arm, and drive wheels. Units are raw encoder ticks (4096 per revolution).

Both arm calibrations were obtained by the automatic routine; the head reference and usable range were recorded manually. The wheel entries preserve the saved configuration and do not certify drive distance or turning geometry.

These values belong to this assembled robot. Do not apply them to another robot without checking its mechanical configuration and joint limits. Export does not change the live robot, enable motors, disable health protection, or establish a successful paddle grasp.
