# Carton tools

Source meshes generated by `../make_parts.py`, now tracked so the robot Mac can fetch them.

| File | Dimensions | Intended use |
|---|---|---|
| `paddle_flap.stl` | 210 × 40 × 6 mm; 60 mm handle + 150 mm blade | Right gripper folds the far flap and presses tape |
| `tape_rest.stl` | 90 × 40 × 18 mm | Supports a pre-cut tape strip with a free pinch tab |

Print the paddle. The tape rest is legacy/optional: the current plan picks directly from the ordered dispenser. The paddle's 210 mm length leaves little clearance on a 220 mm bed;
verify brim, skirt, toolpaths and model bounds in the M5C slicer. Slice these meshes with
the actual printer/material profile. This folder does not contain validated printer G-code.

These are prototype parts. Printed quality, gripper fit, strength, collision clearance,
rest position and tape release have not been validated on the robot. The paddle pickup
fixture/rest is not included here; secure a repeatable accessible pickup location during setup.

See [the connected-Mac handoff](../../docs/carton-connected-mac.md) for station setup.
